Emulação

Escolha o núcleo de Nintendo DS. GBA utiliza mGBA.

Dica: se algum jogo apresentar lentidão, experimente o outro núcleo. O desempenho depende do aparelho.

Dados e privacidade

As ROMs ficam neste aplicativo. Não há conta, sincronização nem envio dos seus jogos.

Armazenamento estimadoCalculando…
Os salvamentos ficam armazenados localmente pelo emulador. Apagar os dados do navegador pode excluir jogos e partidas.

Instalação e conexão

Instale na tela inicial para uma experiência de aplicativo.

O motor EmulatorJS é carregado da CDN, salvo quando sua distribuição completa foi incluída no APK. Sem os arquivos empacotados, o jogo pode exigir internet mesmo após a primeira execução.

Controles e salvamentos

Os botões na tela são fornecidos pelo próprio emulador; teclado e alguns controles Bluetooth também funcionam. No DS, toque diretamente na tela inferior.

Use a barra de ferramentas dentro do jogo para criar ou carregar save states. Salve antes de sair ou alternar de jogo.

Bolso Retro é um aplicativo pessoal independente. Sem ROMs, BIOS ou jogos comerciais incluídos. Use arquivos de jogos e firmware que você tenha direito de utilizar. O núcleo de emulação é fornecido pelo projeto EmulatorJS.
